#  How to contribute

Broadly speaking: *Scryfall Art Game* is not seeking contributions. It is essentially complete, but made available as a public repository under the [X11 licensed](https://en.wikipedia.org/wiki/MIT_License#X11_License) to enable people to study and reference it. “How do they do this thing?” Well, here's how.

Art Game is not currently soliciting new feature additions. It is essentially considered complete, and it's intended to be simple.

If you do wish to contribute:

- Review [the current open issues](https://github.com/scryfall/art-game/issues) and propose a pull request to implement one.
- Propose a new feature in an issue and add the _needs vetting_ label. Check the archive to see if it's been proposed before.

Broadly speaking, changes and proposals should look to keeping the game (and its code and UI) fairly simple.
