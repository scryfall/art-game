#  How to contribute

Broadly speaking: *Scryfall Art Game* is not seeking contributions. It is made available as a public repository and [X11 licensed](https://en.wikipedia.org/wiki/MIT_License#X11_License) primarily to enable people to study and reference it for their own code. “How do they do this thing?” Well, here's how.

*Scryfall Art Game* is not currently soliciting new feature additions. It is considered essentially complete, and it's intended to be kept simple.

If you do wish to contribute:

- Review [the current open issues](https://github.com/scryfall/art-game/issues) and propose a pull request to implement one.
- Propose a new feature in an issue and add the _needs vetting_ label. Check the archive to see if it's been proposed before.

Changes and proposals should look to keep the game (and its code and UI) fairly simple, and focused on the current elements already there which are the core of the game.
